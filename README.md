# Сайт детского центра «ТАЛАНТиЯ»

Новый статический сайт детского центра «ТАЛАНТиЯ» в Челябинске. Проект создаётся вместо устаревшего сайта `dety74.ru`, но не изменяет старый сайт, его домен или опубликованные материалы.

Текущий этап включает утверждённую адаптивную главную страницу и документацию по архитектуре, старым URL и контентной инвентаризации. Каталог, страницы программ, формы, backend и публикация пока не реализованы.

## Технологии

- Astro 5;
- TypeScript;
- Tailwind CSS 4;
- статическая генерация;
- локальные изображения и иллюстрации;
- без базы данных, CMS и полноценного backend.

## Требования

- Node.js 20 LTS или новее;
- npm, поставляемый вместе с Node.js.

Разработка и контрольная сборка выполнялись на Node.js 24.16.0 и npm 11.13.0.

## Установка зависимостей

```bash
npm install
```

Для воспроизводимой установки по зафиксированному `package-lock.json` можно использовать:

```bash
npm ci
```

## Запуск разработки

```bash
npm run dev
```

После запуска Astro выведет локальный адрес сайта в терминале.

## Production build

Проверка типов и создание статической production-сборки:

```bash
npm run build
```

Готовые файлы создаются в каталоге `dist/`. Этот каталог генерируется автоматически и не хранится в Git.

Локальная проверка готовой сборки:

```bash
npm run preview
```

## Структура проекта

```text
├── docs/                 архитектура, инвентаризация и карта старых URL
├── public/images/        локальные изображения и иллюстрации
├── src/components/       компоненты смысловых секций главной
├── src/data/             типы и данные программ
├── src/layouts/          общий HTML-каркас
├── src/pages/            страницы Astro; сейчас только главная
├── src/styles/           глобальные стили и дизайн-токены
├── astro.config.mjs      конфигурация Astro и Tailwind CSS
├── package.json          команды и зависимости
└── tsconfig.json         настройки TypeScript
```

Папки `node_modules/`, `dist/`, `.astro/`, `outputs/` и другие временные материалы исключены из Git.

## Данные, ожидающие подтверждения

Перед созданием каталога и страниц программ владелец центра должен подтвердить:

- какие направления работают сейчас и какие планируются;
- точные возрастные группы;
- филиал каждой группы;
- расписание, цену и продолжительность занятий;
- размер групп;
- преподавателей и сведения, разрешённые к публикации;
- условия бесплатного или платного пробного занятия;
- актуальные акции;
- допустимые фотографии детей и преподавателей;
- актуальные социальные сети;
- канал получения заявок;
- политику обработки персональных данных;
- связь спорных направлений: театр, мультстудия и блогинг; творчество и арт-студия; гимнастика для ума и нейрочтение;
- статус новых кандидатов без старых страниц: нейрочтение, блогинг, бисероплетение и арт-студия.

Подробности находятся в `docs/content-inventory.md` и `docs/client-questionnaire.md`.
