# «ТАЛАНТиЯ» — черновой дизайн-MVP

Статический прототип нового сайта детского центра в Челябинске.

## Технологии

- Astro;
- TypeScript;
- Tailwind CSS;
- статическая генерация.

## Локальный запуск

```bash
npm ci
npm run dev
```

## Сборка

```bash
npm run build
```

Публикация черновой версии выполняется автоматически через GitHub Pages при
отправке изменений в ветку `master`.
