# Сайт детского центра «ТАЛАНТиЯ»

Локальный дизайн-MVP нового статического сайта детского центра в Челябинске. Проект не изменяет старый сайт и домен, не публикуется автоматически и не содержит форм, оплаты, базы данных или админ-панели.

## Технологии

- Astro 5 и статическая генерация;
- TypeScript;
- Tailwind CSS 4;
- локальные изображения и декоративные элементы;
- без клиентского фреймворка и тяжёлых библиотек.

## Требования и команды

Node.js 20 LTS или новее и npm.

```bash
npm ci
npm run dev
npm run check
npm run build
npm run preview
```

Production-сборка создаётся в `dist/` и не хранится в Git.

## Реализованные страницы

- `/` — главная;
- `/programs/` — каталог с фильтрами;
- `/programs/[slug]/` — 20 статически сгенерированных страниц программ;
- `/schedule/` — направления и телефонный CTA для актуальных условий;
- `/events/` — праздники и мастер-классы;
- `/about/` — о центре;
- `/contacts/` — филиалы и автоматические списки программ;
- `/404.html` — страница ошибки;
- `/sitemap.xml` и `/robots.txt` — SEO-основа.

Production build содержит 27 HTML-страниц: главную, каталог, 20 программ, четыре информационные страницы и 404.

## Структура

```text
docs/                          инвентаризация и документы запуска
public/images/                 подготовленные изображения прототипа
src/components/                общие Astro-компоненты
src/components/program-detail/ универсальный шаблон программы
src/data/programs.ts           программы и справочник филиалов
src/data/schedule.ts           модель будущих групп
src/layouts/Layout.astro       HTML-каркас и SEO
src/pages/                     маршруты
src/styles/global.css          токены и системные стили
materials/                     исходники заказчика, исключены из Git
```

## Данные до публикации

Требуются финальные тексты программ, цены, расписание, максимальные возрасты, длительность, размеры групп, условия пробных занятий, согласия на фотографии детей, политика обработки данных, канал заявок и ссылки маршрутов. Информация о педагогах по решению владельца не публикуется.

Полный перечень: [docs/launch-checklist.md](docs/launch-checklist.md).
