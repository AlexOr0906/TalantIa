# Уведомления о заявках во ВКонтакте

VK используется как дополнительный канал после успешной отправки заявки на
email. Если VK временно недоступен, посетитель всё равно получает подтверждение,
а повторно отправлять заявку не требуется.

## Подготовка сообщества

1. Включите сообщения официального сообщества «ТАЛАНТиЯ».
2. В разделе «Управление → Работа с API → Ключи доступа» создайте ключ
   сообщества с минимально необходимым доступом к сообщениям.
3. Не используйте токен личной страницы.
4. Каждый администратор-получатель должен сначала написать любое сообщение
   сообществу. Иначе сообщество не сможет начать диалог первым.
5. Узнайте числовой VK ID каждого получателя.

Токен и числовые ID вводятся только непосредственно на Timeweb. Не передавайте
их в чатах, не добавляйте в Git и не включайте в архив сайта.

## Настройка на Timeweb

Откройте существующий файл:

`public_html/private/lead-config.php`

Добавьте в возвращаемый массив:

```php
'vk_enabled' => false,
'vk_group_token' => 'VK_GROUP_ACCESS_TOKEN',
'vk_peer_ids' => [
    123456789,
],
'vk_api_version' => '5.199',
```

Замените заполнители непосредственно на сервере. Для нескольких получателей
укажите несколько числовых ID. После проверки включите интеграцию:

```php
'vk_enabled' => true,
```

Версия `5.199` выбрана по актуальной официальной схеме VK API. При будущем
обновлении сначала проверьте совместимость `messages.send`.

## Безопасная проверка

1. Оставьте `vk_enabled => false` и отправьте тестовую заявку: email должен
   прийти как раньше.
2. Убедитесь, что каждый получатель написал сообществу.
3. Внесите токен сообщества и тестовый числовой ID на Timeweb.
4. Включите `vk_enabled => true`.
5. Отправьте одну тестовую заявку с заведомо тестовыми данными.
6. Проверьте email и личные сообщения VK.
7. Повторите запрос с тем же `submissionId`: второе письмо и второе сообщение
   VK создаваться не должны.
8. Проверьте журнал ошибок. В нём допустимы только обезличенные сообщения вида
   `[lead] vk delivery failed`; токен и данные заявки там отсутствуют.

## Откат

Для мгновенного отключения VK установите:

```php
'vk_enabled' => false,
```

Email продолжит работать. При компрометации токена немедленно отзовите его в
управлении сообществом и создайте новый.

## Персональные данные

Перед production-включением владелец должен проверить политику обработки
персональных данных и при необходимости явно описать передачу данных заявки
через VK. Готовый юридический текст должен предоставить ответственный за
правовые документы сайта.
