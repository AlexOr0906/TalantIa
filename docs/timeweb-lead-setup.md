# Настройка заявок на Timeweb

Обработчик отправляет заявку на email средствами PHP `mail()`. Настоящие адреса
не хранятся в репозитории и не должны находиться внутри `public_html`.

## 1. Создание приватной папки

В файловом менеджере Timeweb найдите папку `public_html`. Рядом с ней, на том же
уровне, создайте папку:

```text
private
```

Итоговая структура должна выглядеть так:

```text
private/
  lead-config.php
public_html/
  api/
    lead.php
  index.html
```

Папка `private` не должна находиться внутри `public_html`.

## 2. Создание `lead-config.php`

Создайте файл `private/lead-config.php` вручную. За основу можно взять
`deployment/lead-config.example.php`, но заполнители необходимо заменить в
панели Timeweb:

```php
<?php
return [
    'recipient_email' => 'RECIPIENT_EMAIL',
    'sender_email' => 'SENDER_EMAIL',
    'site_name' => 'ТАЛАНТиЯ',
];
```

- `recipient_email` — адрес, на который должны приходить заявки.
- `sender_email` — адрес отправителя на подключённом к хостингу домене.
- `site_name` — название центра.

Не отправляйте заполненный файл в Git, мессенджеры или публичные архивы.

## 3. Права доступа

Для папки `private` установите права `700` или наиболее строгий доступ,
разрешённый панелью Timeweb. Для `lead-config.php` используйте `600` или `640`.
Файл должен читаться PHP-процессом сайта, но не посторонними пользователями.

## 4. Проверка недоступности конфигурации

Попытка открыть адрес вида:

```text
https://технический-домен/private/lead-config.php
```

должна возвращать 404. Содержимое конфигурации не должно отображаться или
скачиваться. Если файл доступен, значит папка создана внутри `public_html` —
переместите её на уровень выше.

## 5. Загрузка обработчика

Загрузите публичную сборку в `public_html`. Проверьте наличие:

```text
public_html/api/lead.php
```

Обработчик не требует PHP-фреймворка, базы данных, Telegram или стороннего
сервиса. На хостинге должна быть доступна функция PHP `mail()`.

## 6. Тестовая заявка

1. Откройте технический сайт в браузере.
2. Нажмите «Оставить заявку».
3. Используйте только специально подготовленные тестовые данные.
4. Подтвердите согласие и отправьте форму.
5. При HTTP 2xx интерфейс покажет подтверждение.
6. При отсутствии конфигурации или ошибке почты интерфейс предложит позвонить и
   не очистит введённые поля.

Не тестируйте обработчик через адресную строку: он принимает только POST JSON с
того же сайта.

## 7. Безопасная проверка журнала ошибок

Проверяйте PHP error log через панель Timeweb. Обработчик пишет только короткие
технические события:

- конфигурация отсутствует;
- конфигурация некорректна;
- почтовый транспорт вернул ошибку.

Имя и телефон посетителя в журнал не записываются. Не включайте вывод ошибок
PHP посетителю и не копируйте содержимое `lead-config.php` в журнал или отчёты.

## 8. Что проверить перед рабочим запуском

- адрес отправителя разрешён настройками почты Timeweb;
- письмо приходит на тестовый адрес;
- конфигурация недоступна через браузер;
- запросы с другого Origin отклоняются;
- повторные клики не создают несколько писем;
- после теста в публичных файлах и Git нет настоящих email-адресов.
