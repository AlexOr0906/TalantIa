# Инвентаризация исходных изображений

## Использование в design-MVP

- `catalog-art-studio.webp` — Hero каталога и страницы арт-студии;
- `catalog-dance.webp` — дополнительный визуал Hero каталога;
- `art-studio-gallery.webp` — Hero страницы `/events/`, поскольку исходный кадр относится к творческому мероприятию, а не к регулярной арт-студии;

- остальные страницы без подтверждённых фотографий используют декоративную систему.
