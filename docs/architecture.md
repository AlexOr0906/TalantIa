# Архитектура сайта «ТАЛАНТиЯ»

## Границы MVP

Статический дизайн-MVP на Astro. Старый сайт, домен и внешние сервисы не изменяются. Базы данных, CMS, форм, CRM, оплаты, личного кабинета и публичного раздела педагогов нет.

## Источники данных

- `src/data/programs.ts` — тип `Program`, 20 программ и справочник филиалов;
- `src/data/schedule.ts` — тип `ProgramGroup`; массив записей пуст до получения расписания;
- неизвестные значения остаются `null`, отсутствуют или представлены пустым массивом и условно не выводятся;
- черновой статус текста хранится в `shortDescriptionStatus` и не виден посетителю;
- источники новых фактов хранятся в `ContentSource`, а состояние контента — в `contentStatus`;
- возрастные варианты, цены и расписание структурированы; интерфейс показывает только значения, помеченные как однозначно публичные;
- информация о педагогах исключена из публичной модели.

## Маршруты

- статические: `/`, `/programs/`, `/schedule/`, `/events/`, `/about/`, `/contacts/`, `/404.html`;
- `src/pages/programs/[slug].astro` использует `getStaticPaths` только для `active` и `planned`;
- неизвестные slug не генерируются;
- `/sitemap.xml` собирается из статических маршрутов и программ.

## Компоненты

- `Layout.astro` — HTML-каркас, `lang="ru"`, canonical, Open Graph и минимальная Organization-разметка;
- `Header`, `Footer`, `Breadcrumbs`, `PhoneCTA`, `DecorativeVisual` — общая система;
- `program-detail/*` — условные блоки шаблона программы;
- `ProgramGallery` не создаёт секцию без подходящих изображений.

## Доступность и навигация

Меню плоское. Возраст и филиал не являются уровнями меню. Используются один H1, семантические секции, skip-link, видимый `focus-visible`, зоны не меньше 44×44 px и мобильное меню с закрытием после перехода и по Escape.

## SEO

`https://dety74.ru/` задан как production site URL только для canonical и sitemap. Это не публикует сайт и не меняет домен. Не используются схемы Course, Person, расписания или неподтверждённые коммерческие данные.

## Изображения

Оригиналы находятся в игнорируемой папке `materials/`. В `public/images/` хранятся оптимизированные копии. Предоставленный набор фотографий, включая снимки с лицами детей, разрешён владельцем для публичного интерфейса 25 июля 2026 года; для будущих материалов требуется отдельное подтверждение.
